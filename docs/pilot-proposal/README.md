## Rendering and checks

Run from the repository root:

```sh
python3 docs/pilot-proposal/build_proposal.py
```

The builder uses Python's standard library and the installed macOS Arial font files. Both fonts are embedded in the PDF. It writes a six-page A4 PDF with selectable text, native vector graphics and three clickable official-source references. HTML contains inline SVG and requires no network assets.

`pdf-checks.json` records page count, text-bound checks, source-link count and byte size. All six PDF pages were rendered with macOS `sips` and visually inspected for legibility, clipping and layout. The final page-3 annotation placement and page-5 heading were inspected again after their small adjustments. No project application code was changed.

The dashboard panel is explicitly an **illustration**, not a live screenshot. The local application was offline, and automatic approval review rejected starting its local server because the approval service reported a usage limit. No server-start workaround was attempted. A browser-independent vector document renderer was used to complete the PDF itself.
